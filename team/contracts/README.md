# Договоры поставки — модуль кабинета Dragan Manager

Страница: `team/contracts.html` (плитка «3. Договоры» в кабинете, кнопка «Договор по заявке» на странице заявки).

## Что где лежит

| Файл | Что это | Кто меняет |
|---|---|---|
| `template.js` | Утверждённый текст договора ред. 3.1 (КЗ/РУ), вариант ИП, допсоглашение, отмена, реквизиты продавцов | только владелец; после правки поднять `version` |
| `settings.js` | Контакты питомника для уведомлений и талон ИП | только владелец |
| `docx-build.js` | Сборка DOCX в браузере | — |
| `app.js` | Форма, проверки, реестр | — |
| `../sql/contracts_v1.sql` | Реестр и нумерация в Supabase | запустить один раз |

## Включить реестр (один раз)

1. Supabase → проект **dragan-manager** → SQL Editor.
2. Вставить весь `team/sql/contracts_v1.sql` → Run.
3. Ожидается строка «Договоры v1 — OK».

До этого шага работает только «Скачать проект DOCX» (без номера).

## Правила

- Номера: `DAS-2026-0001` (ТОО), `IP-2026-0001` (ИП), счёт отдельно по годам; `…-ДС1` — допсоглашение, `…-О1` — отмена.
- Номер выдаёт сервер. Изменить или удалить зарегистрированный документ нельзя; ошибочный — «Аннулировать» с причиной.
- Менеджер видит свои договоры, администратор — все.
- Данные покупателей хранятся только в Supabase. В GitHub — только код и текст шаблона.
- Позиции и цены — из заявки; менеджер меняет только реквизиты покупателя, условия поставки и оплаты, особые условия (на двух языках).
